# 🏮 Lantern Browser

A lightweight desktop browser built with **C++ / Qt 6 / Qt WebEngine (Chromium core)**,
featuring multi-tab browsing, incognito mode, bookmarks, history, download manager,
an AI assistant, theme switching, and more.

> Fully Chinese UI. Zero third-party source dependencies (only the system Qt libraries).
> ~1800 lines of C++.

---

## ✨ Features

- **Multi-tab**: new / close / drag to reorder / `Ctrl+1~9` direct access
- **Incognito mode** (`Ctrl+Shift+N`): separate privacy profile, no history left behind
- **Bookmarks**: `Ctrl+D` to save, one-click open from the bookmark bar, standalone manager
- **History** (`Ctrl+H`): search by title/URL, delete single entries, clear all
- **Download manager** (`Ctrl+J`): pause / resume / cancel / open folder
- **Find in page** (`Ctrl+F` / `F3`), **zoom** (`Ctrl+±` / `Ctrl+0`)
- **Fullscreen** (`F11`), **DevTools** (`F12`, opened in a built-in tab)
- **Export PDF** (`Ctrl+P`), **page screenshot** (`Ctrl+Shift+S`)
- **AI assistant** (🤖): type `/ai your question` in the address bar, or summarize the
  current page with one click (powered by Alibaba Cloud DashScope Qwen, requires your own API key)
- **Themes**: light / dark one-click toggle, plus "force dark web content"
- **Welcome page**: time-based greeting, search box (follows the configured search engine),
  quick links to popular sites
- **Permission prompts**: geolocation / camera / microphone / notifications asked per site

## 🚀 Quick Start

### 1. Requirements

- Linux x86_64
- Qt 6.5+ (with QtWebEngine), GCC / Clang, CMake 3.16+, make
- `curl` needed when downloading dependencies

### 2. Get the QtWebEngine dev files (pick one)

Dependency lookup priority: **system packages > `lib/qt6-dev` > auto-download**.

```bash
# Option 1 (recommended): install system dev packages; build.sh uses system headers automatically
sudo apt install qt6-base-dev qt6-webengine-dev qt6-declarative-dev

# Option 2: auto-download a dependency archive you host yourself (see next section)
LANTERN_QTWEBENGINE_URL=<direct-link> ./scripts/download_deps.sh

# Option 3: copy the lib/qt6-dev directory from a machine that is already set up
```

### 3. Build & Run

```bash
./build.sh                # one-click build, output at build/Lantern
./run.sh                  # launch the browser
./run.sh https://example.com  # or open a URL directly
```

### 4. Configure the AI Assistant (optional)

```bash
# Option 1: Settings → fill in the AI API key
# Option 2: write it manually
echo "your-dashscope-api-key" > ~/.lantern/api_key
```

Then type `/ai your question` in the address bar, or click the "🤖 AI助手" button
on the bookmark bar to summarize the current page.

## 📦 Distributing the Dependency Archive (Important)

The QtWebEngine dev files are large (52MB / 1700+ files). Committing them would
bloat the repository and slow down clones (GitHub's per-file limit is 100MB),
so the repository contains **no dependency files at all**.

Pack once on a configured machine, then restore on any other machine with one command:

```bash
# 1. Pack on the machine where deps are installed
./scripts/pack_deps.sh            # produces qt6-webengine-dev-linux-amd64.tar.gz

# 2. Upload the archive to a cloud drive / object storage / server, get a direct link

# 3. On any other machine (build.sh calls this automatically when deps are missing)
LANTERN_QTWEBENGINE_URL=<your-direct-link> ./scripts/download_deps.sh
```

## 💡 FAQ

- **Build fails: QtWebEngine dev files not found**: pick one of the three options in
  "Get the dev files" above, then re-run `./build.sh`.
- **AI assistant says API key missing**: configure it in Settings, or write it to
  `~/.lantern/api_key`.
- **Pushing to GitHub**: the repo to commit is only ~26 files
  (`src/` 19 files + scripts/docs) — just `git push`. Never commit
  `lib/qt6-dev/` or `build/` (already excluded via `.gitignore`).
- **Downloads in incognito mode**: saved like normal downloads; incognito only
  skips history/login persistence.

## 📜 Technical Notes

- Engine: Qt WebEngine (Chromium) — modern HTML5, WebGL, PDF viewing supported
- Some distros (e.g. Deepin) ship an off-the-record default profile, so the app
  creates its own persistent profile to keep history/login state on disk
- Theming uses QSS + QPalette in two layers; the welcome page receives theme and
  search-engine settings through URL hash parameters
